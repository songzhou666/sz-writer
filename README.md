# sz-writer · 政文通

> **党政机关 / 事业单位 / 国企 / 基层 / 执法岗位的公文写作助手**
> 先选型、后动笔、按权威资产写、交付前六维审核 —— 让 AI 写出**能直接上报、能直接下发的公文**。

---

## 它解决什么问题

| 通用大模型的通病 | sz-writer 的做法 |
| --- | --- |
| 文种用错（把请示写成报告、把通告写成公告） | 内置《党政机关公文处理工作条例》文种判别规则，**选型先于正文**，错配当场提示 |
| 格式不对（字体、字号、页边距、版记全凭感觉） | 严格遵循 **GB/T 9704-2012**，字体 / 字号 / 页边距 / 版心 / 行距 / 红色分隔线逐项锁定 |
| 一股"AI 腔"（空话套话、排比堆砌、"总之"收尾） | 内置去 AI 味负面词表 + 语气调性约束，交付前强制过审 |
| 内容靠"编"（数字、政策文号、事实全靠生成） | **禁止编造**：只填用户给的事实，缺口用 `【待补充】` 占位，事实核对纳入审核维度 |
| 写完没人把关 | **六维双程审核闭环**（自检 + 独立盲审），阻断项打回复审，防"假修复" |

## 核心能力

1. **智能选型** —— 通读全量选型目录，按「行文方向 / 行业 / 场景 / 用途」四维定位，输出选型建议卡；多文体同时命中时不合并，交你挑选并附判别理由。
2. **11 维写作画像** —— 方向、行业、场景、岗位、等级、用途、发文机关、行文对象、素材要素……信息不足宁可反问，也不臆测代填。
3. **文种对错判定** —— 请示 / 报告、通知 / 通告、函 / 请示、批复 / 复函等易混文种，先判再写。
4. **从零起草全文** —— 搭骨架 → 列素材缺口 → 逐段起草 → 整稿装配国标格式。
5. **已有文章优化** —— 润色、语病修正、格式规整、按推荐文种重构、行业语气适配、去 AI 味；不新增事实、不删关键信息。
6. **多维度评估报告** —— 拿来稿按「文体 / 结构 / 语言 / 语气 / 事实 / 去 AI 味」六维打分（满分 100），逐项引用原文证据并给改进建议。
7. **六维审核闭环** —— 文体 / 结构 / 语气 / 去 AI 味 / 事实核对 / 交付规格，双程审核。
8. **联网动态扩展** —— 预置库未命中时，检索 gov.cn、国标、官方模板等权威源，当场提炼结构化临时资产辅助写作。
9. **涉密拦截与合规提示** —— 涉密 / 敏感内容直接拦截；用户坚持错误文种时醒目风险提示。
10. **修订模式** —— 交付后说"改第三段"，保留画像与文种直接进入修订，不重走选型。

## 数据可信度：每一份骨架都来自权威范文

> 不是"让模型自由发挥"，而是把 **10 万+ 篇权威公文**的写作规律沉淀成可复用的结构化资产。

- **来源权威**：筛选对象覆盖国务院及各部委官网、各省市政府公报、党组织文件、正规出版的公文写作教材、权威公文写作学会署名范本。
- **提炼方式**：对每篇优质范文做结构化剖析，提取**必选 / 可选骨架、开头 / 过渡 / 结尾句池、行业禁用词、语气调性、格式排布规则、发文字号规范、版头版记要素**——而非简单摘录原文。
- **质量门槛**：仅采纳符合《党政机关公文处理工作条例》与 **GB/T 9704-2012**《党政机关公文格式》的范文；自媒体口水文、营销软文、个人经验贴一律不入库。
- **资产规模**：**44 族 / 90 小类**，每类均配独立骨架与句池。
- **三级渐进加载**：L0 选型总目录 → L1 族索引 → L2 正文骨架+句池+禁用词，按需加载、不浪费上下文。

## 国标格式，交付即可用

依据 **GB/T 9704-2012《党政机关公文格式》**，随技能自带完整格式参数（无需额外获取）：

| 要素 | 规范 |
| --- | --- |
| 标题 | 方正小标宋简体，二号 |
| 正文 | 仿宋_GB2312，三号 |
| 一级标题 | 黑体三号；二级标题 楷体_GB2312 三号 |
| 页边距 | 上 37mm、下 35mm、左 28mm、右 26mm |
| 版心 | 156mm × 225mm |
| 行距 | 28–30pt（每页 22 行、每行 28 字） |
| 红色分隔线 | 发文字号（及签发人）之下 4mm，红色实线约 0.35mm |
| 页码 | 单页右下、双页左下，宋体四号 |

同时支持：默认国标格式 / 红头文件版头 / 用户自定义格式（用户指定则优先遵从），并可输出 **HTML 交付文件**直接查看排版效果。

## 安装

本仓库**根目录即为技能本体**（`SKILL.md` 在仓库根），安装时不要再套一层目录。正确结果是 `.../skills/sz-writer/SKILL.md`。

**方式一：下载 ZIP（最简单）**
Code → Download ZIP → 解压得到 `sz-writer` 文件夹 → 放入你的技能目录。

**方式二：git clone**

```bash
git clone https://github.com/songzhou666/sz-writer.git
```

然后把 `sz-writer` 文件夹放进技能目录：

| 你的环境 | 技能目录 |
| --- | --- |
| TRAE | 项目内 `.trae/skills/`（或用户级技能目录） |

在 [SkillHub](https://skillhub.cn) 搜索「政文通 · 公文写作助手」，进入详情页点安装即可，无需手动放目录。

## 常见问题

**Q1：和直接让大模型写公文有什么区别？**
差别在于"依据"。大模型凭训练记忆写，文种、格式、语气全看运气；sz-writer 是先定位文种、再加载该文种的权威骨架与句池、装配国标格式、最后过六维审核，每一步都有据可查。

**Q2：会不会编造政策文号或数据？**
不会。技能强制"只填用户给的事实"，缺口用 `【待补充】` 占位；事实核对本身就是审核的六个维度之一，编造会被拦下。

**Q3：我想写的文种不在 44 族里怎么办？**
两条路：① 联网检索 gov.cn / 国标 / 官方模板等权威源，当场提炼临时资产辅助写作；② 用通用骨架兜底起草（会明示局限）。两种情况都**不会**先收费。

**Q4：一次写作要花多少钱？**
0.50 元，覆盖 120 分钟内的全部资产调用。同一窗口内换文种、另起新篇、反复修改对比，都不再重复计费；评估 / 改写 / 格式规整等能力本身不额外计费。

**Q5：涉密内容能用吗？**
不能。技能内置涉密 / 敏感内容拦截，命中即停止处理并提示。

**Q6：生成的是 Markdown 还是能直接用的公文？**
可交付 Markdown 或 **HTML 排好版的公文**（含国标字体字号页边距），也可按你的单位模板自定义格式。

**Q7：文种我拿不准，它能帮我判断吗？**
可以，这正是它的强项。你直接描述事情经过，它会给出选型建议卡并附判别理由，由你拍板。

**Q8：需要我自己准备范文吗？**
不需要。预置 44 族 90 小类的结构化资产；你有本单位范文时也可以贴进来，它会按你的范文风格对齐。
