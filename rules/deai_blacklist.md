# 去AI味负面词表（应用文 · 三层 + 白名单）

> 作用对象：S6 起草前置约束 + S7 去AI味审核（含《应用文评估报告》的去AI味维度）。
> 判定原则见 `rules/audit_rules.md` 六、去AI味检测规则（R1~R7）。

## D.1 第一层 · 网感黑话（硬禁：正式公文出现即 BLOCK-去AI味-黑话）
赋能、抓手、闭环、颗粒度、底层逻辑、链路、飞轮、生态、矩阵、沉淀、打通、护城河、天花板、
王炸、封神、稳了、保姆级、绝绝子、YYDS、划重点、上强度、可圈可点等商务/自媒体黑话。

> 判定补充：黑话是否破坏正式语境；若用户素材里明确为政策原文引用（如上级文件原词"赋能"），
> 标注引用来源后可保留，不判阻断。

## D.2 第二层 · AI 高频词（词频监控：超阈警告，非禁用）
此外、同时（句首）、另外、值得注意的是、需要指出的是、值得一提的是、综上所述、总而言之、
毫无疑问、毋庸置疑、不言而喻、至关重要、不可或缺、众所周知、不仅仅……而且、不仅……更、
作为……（万能状语开头）。

> 默认阈值：同一词/短语全文出现 >2 次即警告；"不仅…而且/不仅…更"类结构全篇 >2 处即警告。

## D.3 第三层 · 空转句式与结构套路（检测 + 提示改写）
- 万能结尾：在……的指引下，我们将…… / 让我们共同…… / 相信在……的共同努力下，必将…… /
  总之，我们坚信…… / 为实现……而努力奋斗（脱离事实的泛化版）。
- 空转开头：随着……的不断深入 / 在当前……的大背景下。
- 结构套路：连续 ≥3 段以"一是…二是…三是"同构开头；每段均"总-分-总"；三连形容词堆砌
  （更高站位、更严标准、更实举措——当无实质内容承接时）。

> 空转段判定："删除该段后不影响任何信息完整度" → 判空转，列修改建议。

## D.4 白名单（公文体式合规，不判 AI 味）
- 国标固定套语：妥否，请批示 / 妥否，请批复 / 特此通知 / 特此通告 / 特此函达 / 特此函复 /
  此复 / 此告 / 现就……通知如下 / 现将……报告如下 / 现予发布。
- 政务常规动词（仅查词频轰炸，不查单次）：进一步、切实、加强、推动、落实、强化、提升、
  完善、深化、健全、规范、统筹。
- 法定引用语与政策原文：不得口语化改写。

## 真数据铁律（与采集端同一把锁）
用户画像/素材回链可定位的真实数据（单位实际数字、真实文号、真实日期、人名职务、案例、
附件清单）——去AI味只许改表达，绝不改/删数据本体。命中词频/数字扎堆等信号时先判断出处：
有出处即真，保留（仅调表达）；无出处且查无实据才按编造剔（对应 BLOCK-事实）。
