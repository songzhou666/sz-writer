# 审核规则（政文通·公文写作助手 · 全量）

> 作用对象：S7 六维审核（自产稿）＋ 任务类型 C／评估模式（用户来稿）。双程审核＋阻断打回＋防假修复。
> 交付铁律：**不经过 S7/评估，任何正文不得作为终稿交给用户。**

## 一、六维审核总维度（审什么 / 以什么为基准）
| 审核维 | 审什么 | 判定基准 | 典型命中示例 |
| --- | --- | --- | --- |
| ① 文体 | 文种与内容是否匹配、行文方向是否正确 | 选型建议卡 + 文体对错判定标准 | 请示内容写成报告、请示结尾用"特此通知" |
| ② 结构 | 模块排布是否合规完整、一文一事 | 命中资产的结构骨架（必选/可选/排布） | 请示缺结语、目录乱序、一文多事 |
| ③ 语气 | 语体与对象感是否准确、有无禁用语气 | 资产"语气要点" + 禁用语气；行文方向称谓体系 | 上行不谦恭（无恳请/妥否）、函居高临下 |
| ④ 去AI味 | 词频轰炸/空转段/模板腔/黑话/事实密度 | 去AI味负面词表 + 检测规则（R1~R7） | 硬禁黑话、万能结尾、无数据空转 |
| ⑤ 事实核对 | 用户给定的数字、日期、百分比是否逐项落地终稿 | 用户素材清单（逐项在终稿检索比对） | 用户给"3 个乡镇/87%/2025-03-01"却在终稿 0 命中、或与素材矛盾 |
| ⑥ 交付规格 | 字数是否达标、格式要素是否完整、合规差异是否提示 | 用户交付规格 + GB/T 9704 格式要素清单 | 要求 ≥800 字实测仅 600 字；漏附件说明；删法定要素未提示 |

**新增两维的可判定标准**：
- **事实核对（项—命中次数）**：从用户素材中抽取全部数字、日期、百分比逐项在终稿检索，输出"项—命中次数"清单；**任一项命中次数 = 0 → 判 `BLOCK-事实`**；与素材数值直接矛盾同样判 `BLOCK-事实`。
- **交付规格**：字数类要求以**中文字符数（正文，不含标题落款）**为统一口径交付前实测并报告；格式要素逐项核对完整性；凡用户要求删除法定要素（发文字号/签发人/主送机关/附件说明等）或与国标冲突的，须在交付摘要列明**合规差异提示**，缺提示记警告。此外，交付摘要**固定包含「依据与来源说明」板块（三行）**：① **所用资产**——本篇依据 `{族}→{小类}` 的精细化资产（L2）起草；若为联网提炼的临时资产，注明来源 URL 并明示"现场联网提炼"；若为通用骨架兜底，按兜底铁律明示；② **权威出处**——引用该资产"来源背书/句→出处映射"中的具体条目（如 gov.cn 文件名与条款、GB/T 9704-2012 的具体条款号），**不得编造来源**，资产中没有出处时如实写"该文种资产未标注具体出处"；③ **格式依据**——写明采用的国标格式参数（字体/字号/行距/版心），存在字体替换或删减法定要素等合规差异时一并列出提示。此为交付必做项，**缺失该板块即记警告**。

## 二、文体对错判定标准（国标）
- 请示 vs 报告：需上级批复=请示；仅汇报不需答复=报告，混用必提示。
- 通知 vs 通告：对内特定单位=通知；对外社会公众=通告。
- 函 vs 请示/通知：平行往来=函；向上=请示；向下=通知。
- 批复 vs 复函：答复下级请示=批复；答复平行来函=复函（函子类目不独立文种）。

## 三、双程审核
- 第一程·起草自检：S6 起草产出草稿后立即按六维自查，不通过就地修改。
- 第二程·独立盲审：以"刻薄读者"身份重读终稿，**不看起草过程**，仅依据正文 + 文种基准资产 + 用户画像/意愿，逐句挑刺。
- **证据引用铁律（防假通过）**：每个扣分/判定必须引用正文具体句子或位置；禁止"整体不错/基本合格"式无依据结论。

## 四、阻断项（一票否决，命中必须打回并复审）
| 阻断码 | 触发条件 | 打回目标 |
| --- | --- | --- |
| BLOCK-文体 | 文种与内容本质冲突 | 回 S5 重确认或按正确文种重写 |
| BLOCK-结构 | 缺必选模块、结语用错、一文多事、乱序 | 重排骨架后重写相关段 |
| BLOCK-语气 | 用禁用语气、对象严重错位 | 语气修正 |
| BLOCK-去AI味-黑话 | 正式公文出现网感硬禁词 | 立即替换 |
| BLOCK-去AI味-空转 | 空转段 ≥30% 正文 或含万能结尾 | 删除/改写为有信息内容 |
| BLOCK-事实 | 凭空编造数据/单位/文号；与用户素材矛盾 | 按素材修正或改【待补充】 |
| BLOCK-格式 | 字体/字号/版式不符合国标（见 SKILL.md §5.5）或用户明确的格式规格 | 按国标格式参数修正 |
| BLOCK-安全 | 涉密残留复查未过 | 阻断交付 |

- 打回后**必须重审**，禁止跳过；重审发现"声称已修实际未修/只修表面"→判定**假修复**→再次打回。
- 同一阻断累计 3 次仍未过 → 升级：提示人工介入或降级交付（如实告知局限）。

## 五、警告项（不阻断，随交付列明）
AI 指纹词密度超阈（未到黑话级）、高频连接词超次、句均长过于均匀、可优化项 → 列为"可继续优化"提示，用户可一键发起下一轮优化。

## 六、去AI味检测规则（机器化 R1~R7，对应用文负面词表）
| 规则 | 判定 | 级别 |
| --- | --- | --- |
| R1 硬禁词命中 | 负面词表 D.1 命中正文 | 阻断 |
| R2 指纹词密度 | 每千字命中 D.2 ≥8 次 | 警告 |
| R3 单词超频 | 同一 D.2 词 >2 次 或 D.4 政务常规动词（进一步/切实/加强/推动/落实/强化/提升/完善/深化/健全/规范/统筹）全文 >5 次 | 警告 |
| R4 空转段 | 存在 D.3 模式或"删后无损"段；占比 ≥30% 正文 | 阻断(≥30%)/警告(<30%) |
| R5 排比失控 | 排比段 ≥60% 正文 且关键排比无事实承接 | 警告 |
| R6 无数据段 | 请示/报告/方案类正文连续 2 段无数字/单位/具体对象 | 警告 |
| R7 万能结尾 | 末段命中 D.3 万能结尾 | 警告 |

**去AI味边界铁律（防矫枉过正）**：国标固定套语与政务常规动词（妥否请批示/特此通知/此复/进一步/切实）属合规范围不误删；排比是公文合法修辞仅当无事实且占比过高才判空转；政策原文引用不口语化；**真数据必须保留**（见负面词表"真数据铁律"）。

## 七、涉密残留 / 格式 / 用户意愿复核
1. 涉密残留：终稿再过一遍 S1 检测。
2. **GB/T 9704 格式要素审核**（基准通过 `load_common` API 获取 `gb_format`；若 API 调用失败，以下方列出的基本格式规则为准，不得跳过格式审核）：
   - **标题**：2号方正小标宋简体，居中；三要素（发文机关/事由/文种）齐全。
   - **主送机关**：3号仿宋_GB2312，顶格，后标全角冒号；上行文主送唯一。
   - **正文**：3号仿宋_GB2312，首行缩进2字符；层次序数规范（一、（一）1.（1））。
   - **层级标题**：一级黑体3号、二级楷体_GB2312 3号、三级仿宋加粗3号。
   - **成文日期**：阿拉伯数字全写，右空4字。
   - **落款署名**：成文日期之上居中排布。
   - **附件说明**：正文下空一行左空2字，名称后不加标点。
   - **行距**：28-30磅固定值。
3. **版头（红头文件）审核**（启用版头时，要素自上而下顺序见 GB/T 9704-2012 §7.2）：
   - 发文机关标志：初号方正小标宋简体，红色，居中；全称+文件或规范化简称。
   - 发文字号：标志下空二行，3号仿宋，居中（下行/平行）或居左空一字（上行）；六角括号〔〕。
   - 签发人：仅上行文标注，3号仿宋"签发人"+3号楷体姓名，居右（与发文字号同行）。
   - 红色分隔线：印在**发文字号（及签发人）之下 4mm 处**，居中、与版心等宽，红色实线；线高国标未强制规定，建议约 0.35mm。
   - 密级/紧急程度：3号黑体，版心左上角。
4. **用户自定义格式优先**：用户明确指定字体/字号/行距/页边距/红头等时，以用户要求为准，交付摘要注明与国标的差异。
5. 用户意愿：未偷改用户坚持的文种；画像单与终稿事实一致。
- **豁免确认**：阻断项源于用户坚持（如明确保留某空泛段）须经用户明示同意后才可豁免，且记入审核报告；不得静默放行。

## 八、评估模式挂接（任务类型 C / 用户来稿）
对用户提供的**已有应用文**做分析与评估时，不进入"阻断打回"流水线，改用 `rules/eval_report_template.md` 输出
**《应用文评估报告》**（多维度打分 + 证据引用 + 改进建议 + 可一键改进链接）；仅当文体严重错配时给出文体诊断与三选一建议。

## 九、联网扩展挂接（预置未命中）
选型无命中或用户点名未收录文体时，按 `rules/online_extend.md` 触发联网兜底，提炼《临时文体资产卡》作为该次创作的临时基准；临时资产同样过 S5 确认 + 本规则审核。
