# 资产加载协议（三级 L0/L1/L2）

> 核心机制：**所有资产内容通过付费 API 下发，Skill 包内不包含资产文件。** L0/L1/L2 均需调用 API 获取。

## 平台说明
- **资产获取**：所有资产（L0 选型目录、L1 族索引、L2 正文、通用规则）统一通过付费 API 获取，调用方式见 `SKILL.md §9`。Skill 包内不附带任何资产文件，禁止尝试读取本地 `assets/` 路径。
- **联网能力**：联网动态文体扩展为可选能力，平台不支持联网时，未收录文体自动降级到通用骨架库（通过 `load_common` API 获取）并明示"该文种精细化资产建设中，以下为通用框架"。

## 目标
LLM 如何从全部已入库正文资产中，用最少步数、最小 token 定位并读入"恰好该用的 1 份"，且不因记忆偏差选错文种。

## 三级加载总表

| 级 | 加载时机 | API action | 产出 | 体量 |
| --- | --- | --- | --- | --- |
| L0·选型 | S4 起，常驻 | `list_catalog` | 画像 → 候选族 ≤3 | 约 3k 字 |
| L1·按族 | S4 确认候选族后 | `load_index` | 精确到唯一小类 + 正文路径 | 约 1k 字/族 |
| L2·正文 | S5 确认后 | `load_body` | 完整创作载荷（骨架/句池/禁用/模板/格式） | 2~4k 字 |

## 定位规则（机器约束 + LLM 判定双层）
1. **L0 快速过滤**（调用 `list_catalog` 获取选型目录）：
   - 先按行文对象身份层级判定方向（上级→上行；下级→下行；平级→平行；公众→对外公示；内部→对内）。
   - 在对应方向分组内，用业务场景关键词匹配"典型场景"列，锁定 ≤3 候选族。
   - 跨方向场景（如"经费"既可能请示也可能函）同时取相关方向的候选族。
2. **L1 精定位**：调用 `load_index` 读取候选族索引（≤3 个），用"场景关键词 × 业务场景"模糊命中 + 用途/等级加权 → 定唯一小类。
   - **冲突不合并**：族内 ≥2 个小类同时命中时，禁止自行合并或二选一，回选型建议卡让用户挑并给出判别语。
3. **L2 声明门控**：调用 `load_body` 获取正文前，回复须先声明 `[资产引用] {族}→{小类}`；**无此声明的起草视为违规穿越（产物门控）**。
4. **缺档兜底**：族索引给了路径但正文缺失/建设中 → 调用 `load_common` API（`name=skeleton_base`）获取通用骨架并明示"该文种精细化资产建设中"。
5. **跨族相似场景对照**：候选同时落在两族（如 申请书-经费申请 vs 请示-经费请示）时，两族索引都读，用对照行给出判别（上行求批复→请示；内部/平级申领→申请书）。

## 族索引行格式（一行一小类，≤120 字）
```text
小类|方向|行业|场景关键词|用途|等级|骨架一句话|语气|就绪|→API load_body(family, sub)
```
> 就绪取值：`已入库`（可推荐、可起草，配套正文）/ `试用`（仅备选，注明"内容待完善"）/ `建设中`（不呈现）。

## 规则文件加载说明
除 L0/L1/L2 资产加载外，以下规则文件按阶段常驻或按需加载（**规则文件随 Skill 包分发，可直接读取**）：

| 规则文件 | 加载时机 | 说明 |
| --- | --- | --- |
| `rules/deai_blacklist.md` | S6 起草前常驻 + S7 审核 | 起草前置规避 + 去AI味审核基准 |
| `rules/audit_rules.md` | S7 六维审核常驻 | 阻断/警告判定、双程审核、格式审核 |
| `rules/html_template.md` | S7 交付时按需 | HTML 格式化输出 |
| `rules/eval_report_template.md` | 任务类型 C（评估）按需 | 六维评估报告 |
| `rules/online_extend.md` + `rules/temp_asset_template.md` | 联网兜底时按需 | 未收录文体扩展 |

> 国标格式规范（字体/字号/页边距/版头）通过 `load_common` API 获取，不随 Skill 包分发。

## 运行时动作铁律
1. 起草前必须先通过 API 读到 L2 正文，以其中的"必选骨架、开头/过渡/结尾句池、禁用与语气、格式规则"作为起草约束。
2. **禁止仅凭模型训练记忆写正文**；正文未命中 → 调用 `load_common` API（`name=skeleton_base`）获取通用骨架降级，或按 `rules/online_extend.md` 触发联网兜底。
3. 索引/规则文件只读不改；正文只读不缓存。
4. **禁止尝试读取本地 `assets/` 路径**——所有资产必须通过付费 API 获取。
5. **API 调用失败时禁止跳过**：
   - 返回 400（`INVALID_PAYMENT_PROOF`，凭证过期/无效）→ 按 SKILL.md §9.4 处理，重新支付或用同一凭证重试，不得用记忆写。
   - 返回 404（资产不存在）→ 调 `load_common(name=skeleton_base)` 降级，明示用户"该文种精细化资产建设中"。
   - 返回 500/503 或网络超时 → 用同一 Payment-Proof 重试 1 次，仍失败则终止并告知用户，不得用记忆写。
6. **拿到资产必须用**：起草骨架必须逐条对应 L2 正文中的"必选骨架"模块，开头/过渡/结尾必须基于句池，禁用词必须严格规避。
7. **降级必须明示**：使用通用骨架或联网临时资产时，必须在回复开头告知用户，不得假装拥有精细化资产。

## 防胡编自检清单（起草前逐条确认，任一不满足禁止起草）

- [ ] 骨架逐条对应资产"必选骨架"模块？
- [ ] 开头/过渡/结尾来自或基于资产句池？
- [ ] 已规避资产中标注的禁用词和禁用语气？
- [ ] 资产获取失败时已重试或告知用户，未凭记忆写？

## 会话预算
- 单会话默认只读 1 份 L2 正文（"从零起草 + 改稿续写"最多 2 份）；多族对比 L1 ≤3 份、L2 ≤2 份。
- S7 六维审核/评估复用同一份 L2 正文做基准，不重复读取。
